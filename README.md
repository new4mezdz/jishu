# 拍照数签与棒材端面计数

通过识别照片中每一个可见端面的位置，统计签子或棒材数量，并支持逐点检查、人工补点、删除误检和撤销。自动检测结果与人工修正结果分别保存，为后续专用模型训练积累标注数据。

## 项目状态

当前版本完成需求整理，尚未实现应用。第一版目标是本地运行的 Web 工具，完成上传照片、框选区域、自动检测、逐点标记、人工纠错和保存导出的完整流程。

首期验证场景为密集排列的白色圆形或近圆形棒材端面。竹签等其他场景需要使用对应真实照片独立验证。当前尚未收录原始样图，也没有经过人工核对的数量真值。

## 需求文档

[密集签子与棒材端面自动计数需求](docs/requirements.md) 定义功能范围、人工核对状态、坐标规则、检测接口、数据保存、效果评估和首期验收标准。

## 实施顺序

1. 图片上传、方向处理、原图显示与识别区域选择。
2. 传统算法检测与逐点标记。
3. 缩放、拖动、人工补点、删点及撤销。
4. 保存原始检测与修正结果，导出带标记图片和 JSON、CSV。
5. 密集场景优化、重叠切片与跨切片去重。
6. 数据整理、专用模型训练及同一批独立测试照片上的效果比较。

建议使用 Python、FastAPI、OpenCV 和 Vue 3、Canvas，首期支持 CPU、本地处理图片。技术栈可在实施时根据实际项目情况调整。

## 开发约定

- 测试代码、测试照片副本、测试结果和报告放在项目目录外的独立目录，例如 `D:\9090\jishu-validation`；不得写入当前项目或加入 Git 提交。
- 项目中可以记录测试的运行方式和外部目录约定。后续实现时补充可复现的启动说明、接口说明和参数说明。
- 本地上传图片、用户标注、导出文件及模型权重不默认提交到仓库。
- 未经验证的样图数量估计不得用作训练标签、验收答案或程序常量。
